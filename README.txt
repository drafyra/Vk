# Vicky ❤️ Kashish — Interactive Love Story

## Files
- `index.html` — main website
- `style.css` — cinematic responsive design + animations
- `script.js` — touch hearts, 3D tilt, envelope, fireworks, music controls
- `photos/` — the 5 supplied couple photos
- `music/` — put your own `romantic.mp3` here

## Music
A music player is already wired to:
`music/romantic.mp3`

The ZIP intentionally does not include a copyrighted song. Add a royalty-free/your-own MP3 with that exact filename.

## Run
Open `index.html` directly in a browser, or upload the whole folder to GitHub Pages/Netlify/etc.

## Main interactions
- Touch/click empty screen → floating hearts
- Tap the big heart → heart burst
- Tap envelope → letter modal
- Tap “TAP FOR A SURPRISE” → full-screen fireworks + hearts
- Music button → play/pause
